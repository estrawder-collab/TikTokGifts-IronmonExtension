# Nat. Dex Abilities patch (optional)

`pokefirered_natdex_1.2.2_abilities.bps` is an optional ROM patch for Nat. Dex FireRed 1.2.2. The TikTok Gifts extension does not need it.

- Apply it to a Nat. Dex FireRed 1.2.2 ROM (CRC32 `34AAFED7`). The patched ROM has CRC32 `EBD4339B`.
- What it changes, how to apply it and what to know first: see [Optional: Nat. Dex Abilities patch](../../README.md#optional-nat-dex-abilities-patch) in the main README.

No ROM is included. You supply your own game file.
